# AI-Assisted Coding Policy

## Human accountability

A human reviewer remains responsible for code, tests, configuration and releases. AI output is untrusted until reviewed and verified.

## Permitted use

AI may assist with analysis, implementation, tests, documentation and repository operations within granted permissions.

## Prohibited use

- submitting secrets or customer data;
- bypassing security or quality gates;
- autonomous production deployment without approved controls;
- accepting tests or claims without execution;
- using unapproved MCP servers or plugins;
- merging without required human review.

## Evidence

Pull requests must record commands executed, results, significant AI-assisted areas and unresolved limitations.
