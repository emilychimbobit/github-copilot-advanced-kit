# Architecture Decision Records

Nombra los ADR como `0001-titulo-corto.md`.

Para calcular el siguiente número, ejecuta `python scripts/next_adr_number.py`.
Hay un hook de ejemplo (deshabilitado) que valida la numeración tras editar
`docs/adr/*.md`: `examples/hooks/adr-next-number.hooks.json.disabled`.

Estados permitidos:

- Proposed
- Accepted
- Superseded
- Deprecated
- Rejected

Usa el skill `/adr-authoring`.
